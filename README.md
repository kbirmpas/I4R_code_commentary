# I4R_code_commentary

This is the code accompanying the Abreu et al commentary. 
"claims_script.R" contains the code created by the I4R toolbox to generate claims on the reproducibility of the paper's results.
The folder supplemenatry_code_R includes code generated on top of the scripts created by the toolbox to elaborate more on the nuances of the reproducibility obstacles observed and tackle those in a way that reconciles once again the reported results to the original dataset
