# Supplementary R scripts — Abreu et al. commentary

These are additional scripts drafted on topof thecode provided by I4R 
## Contents

- `01_claim1_activity_subgroups.R` — alternative activity-classification rules; three-group medians; rank-sum comparisons of the eight disputed Active and 14 Sedentary participants; complete-rank-separation check. The user shared R output for these analyses in the conversation.
- `02_claim2_sensitivity_diagnostics.R` — standalone version of the extended Claim 2 checks we drafted, including leave-one-out p-values and **additional** raw-versus-control-adjusted group summaries.  
- `03_claim3_baseline_checks.R` — expanded descriptive pre/post, control-cancellation, paired and baseline-adjusted regression checks drafted in the conversation.  
- `04_claim4_power_checks.R` — independent base-R noncentral-F power calculations, effect-size comparisons, correlation sensitivity, exploratory three-measure reconstruction, 



## Data

The scripts for Claims 1–3 expect the original deposited workbook at:

`pkg/Dataset_Abreu et al.xlsx`

relative to the R working directory. The optional part of Claim 4 looks for the same file. Obtain it from the original study's OSF repository (https://osf.io/dvqxz/). To avoid unnecessarily redistributing participant-level data, **the workbook is not bundled here**.
